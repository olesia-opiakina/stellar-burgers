# Проект Stellar Burgers

Одностраничное веб-приложение для создания бургеров с возможностью оформления заказов, авторизации пользователей и управления личным кабинетом.

## Демо

<https://stellar-burgers-project.netlify.app/>

## Стек технологий

React, TypeScript, Redux Toolkit, React Router, HTML5, CSS Modules, Webpack, Jest, Cypress

## Функциональность

- Конструктор бургеров с возможностью перетаскивания ингредиентов (Drag & Drop)
- Просмотр подробной информации об ингредиентах в модальном окне или на отдельной странице
- Оформление заказов с отображением номера заказа
- Лента заказов с возможностью отслеживания их статуса
- Просмотр подробной информации о заказах в модальном окне или на отдельной странице
- Регистрация и авторизация пользователей
- Личный кабинет с редактированием профиля, сменой пароля и историей заказов
- Защищённые маршруты для авторизованных пользователей

## Запуск проекта

### Установка и запуск

```bash
git clone https://github.com/olesia-opiakina/stellar-burgers.git
cd stellar-burgers
npm install
npm start
```
### Переменные окружения

Для корректной работы запросов к серверу необходимо создать файл `.env` в корне проекта и добавить в него переменную:
```env
BURGER_API_URL=https://norma.education-services.ru/api
```
### Production-сборка

```bash
npm run build
```

После выполнения команды собранная версия проекта будет находиться в папке `dist`

## Тестирование

В проекте реализованы:

- Unit-тесты на Jest для Redux Store и Redux-слайсов.
- Интеграционные тесты на Cypress для конструктора бургеров, модальных окон и оформления заказа.

### Запуск тестов

```bash
# Unit-тесты
npm test

# Интеграционные тесты
npm run cypress:open
```
